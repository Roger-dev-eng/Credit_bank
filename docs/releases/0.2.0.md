Atualizações pela internet dentro do aplicativo, com confirmação para instalar, progresso do download e verificação de assinatura.

O banco local permanece separado da instalação. Antes de aplicar uma atualização, é criado um backup consistente; durante a troca, novos lançamentos ficam bloqueados. Migrações de esquema também criam backup antes de alterar bancos existentes.

A primeira instalação da versão 0.2.0 deve ser feita com o instalador. As versões anteriores não possuem o mecanismo de atualização.

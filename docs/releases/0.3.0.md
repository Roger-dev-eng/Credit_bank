Interface organizada com Atomic Design: átomos, moléculas, organismos e template de navegação.

- Novo cliente direciona automaticamente para a simulação, já selecionado.
- Contratos identificados pelo nome do cliente e pesquisáveis por nome, identificador, modalidade ou status.
- Preenchimento sutil ao passar o mouse e indicação de foco nos links de contratos e de clientes.
- Atualizações em uma página própria no menu lateral, separada de Dados e segurança.
- Imagem lateral do instalador centralizada, com ícone maior e fonte em resolução 3x.

O banco de dados é preservado, com as proteções e backups automáticos da atualização.
